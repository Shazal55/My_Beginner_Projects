# 🌍 Higher-Lower: Country Population Game

A simple terminal-based Python game where you guess which country has a higher population. Inspired by the classic **Higher-Lower** format, this game tests your world knowledge using real-world population data.

---

## 🕹️ How to Play

1. You're shown two random countries.
2. You guess which one has the higher population by typing `A` or `B`.
3. If you're correct, your score increases.
4. The game continues until you make a wrong guess.

---

## 📦 Features

- 50 real-world countries
- Population data (in millions)
- Official languages & continents
- Score tracking
- Clean console output
- ASCII art for fun visuals 🎉
